# 页面类型：目录页

## 提示词片段

```
PAGE TYPE — TABLE OF CONTENTS. Use a precise numeric index on a stable grid. Prefer a
vertical index, a 12-column index, or a left-title/right-list composition. Use
{STRUCTURE} for numbering and rules, {FOCUS} on at most one active marker, {BORDER} for
hairline separators, and {SURFACE} only where grouping is necessary. Do not turn every
chapter into an identical floating card and do not add decorative icons to every item.
```
