# 页面类型：总览页

## 提示词片段

```
PAGE TYPE — OVERVIEW. Present the page as one coherent visual system: a single relationship
map or a small set of aligned modules. Use {STRUCTURE} for the shared framework,
{SURFACE} for grouped regions, {BORDER} for separation, and {FOCUS} for only the central
or currently emphasized element. Keep module geometry and spacing consistent; avoid a
wall of unrelated cards and avoid using a different color for each module.
```
