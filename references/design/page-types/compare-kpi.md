# 页面类型：对比/数据页

## 提示词片段

```
PAGE TYPE — COMPARISON OR KPI. Make the comparison logic visually explicit with a clean
two-side structure, a dominant number, or a restrained single-hue chart. Use
{TEXT_PRIMARY} and neutral tones for context, {STRUCTURE} for the main data series or
framework, and {FOCUS} for only the decisive value. Semantic colors may appear only when
the content truly represents status, warning or risk. No rainbow chart, ornamental gauge
cluster, or unsupported decorative statistics.
```
