# 页面类型：实施计划页

## 提示词片段

```
PAGE TYPE — ROADMAP. Use one visual spine: horizontal stages, vertical milestones, or a
stage-gate engineering rail. Keep all stages geometrically consistent. Use a neutral or
{BORDER} treatment for inactive stages, {STRUCTURE} for the active sequence, and {FOCUS}
for at most one current or decisive gate. Avoid a collection of disconnected cards,
multiple gradients, and a different icon or color for every stage.
```
