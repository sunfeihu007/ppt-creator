# 页面类型：架构图页

## 提示词片段

```
PAGE TYPE — ARCHITECTURE. Use a strict layered, center-radiating, or left-to-right system
composition chosen from the supplied layout hint. Keep nodes aligned, labels readable and
connectors unambiguous. Use {STRUCTURE} for layers, boundaries and connectors,
{SURFACE} for modules, {BORDER} for secondary separation, and {FOCUS} on only one core
layer or key node. Prefer flat legibility for dense systems; do not make every node a
different 3D object and do not place texture behind small labels.
```
