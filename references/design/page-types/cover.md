# 页面类型：封面页

## 提示词片段

```
PAGE TYPE — COVER. Build one focal composition, not a dashboard and not a card matrix.
Reserve roughly 35–45% of the canvas for the title system and 45–60% for one signature
visual. Use {BACKGROUND} as the dominant field, {STRUCTURE} for the visual framework and
{FOCUS} only for one restrained focal detail. Keep the subtitle and metadata secondary.
No architecture labels, no repeated feature cards, and no decorative icon wall.
```
