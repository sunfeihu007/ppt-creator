# 页面类型：客户案例页

## 提示词片段

```
PAGE TYPE — CUSTOMER CASE. Give priority to supplied real photography, product screenshots,
site images or verified customer assets. Use a consistent image ratio and crop treatment,
then add one restrained evidence band or annotation panel in {SURFACE}. Use {STRUCTURE}
for framing and {FOCUS} for one result marker. Never invent a customer logo, never use a
generic business-person stock scene, and do not cover the primary image with a large glass
card. If no real image exists, keep the composition honest and diagram-led.
```
